# Lua States Folder

This folder contains Lua files that define different game states.

## Contents:

*   `gameState.lua`: Likely manages the overall game state, such as levels, scoring, and game over conditions.
*   `playerState.lua`: Probably handles the player's specific state, including health, inventory, position, and abilities.
*   `shopState.lua`: Likely manages the state of the shop, including available items, prices, and inventory.

These files likely use the module pattern to encapsulate their functionality and expose a table of functions and variables.
